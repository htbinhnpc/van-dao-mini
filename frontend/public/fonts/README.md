# Local typography

Noto Serif WOFF2 subsets (Latin, Latin Extended, Vietnamese), obtained from Google Fonts on 2026-11-04. Distributed under the SIL Open Font License in `OFL.txt`. Font source: https://github.com/google/fonts/tree/main/ofl/notoserif

Local serving avoids third-party font requests and inconsistent Vietnamese serif fallbacks. Main interface text keeps the original game's system-font family.
